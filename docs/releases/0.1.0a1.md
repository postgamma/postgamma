# PostGamma 0.1.0a1

Status: unreleased alpha candidate.

This is the first Python product and static C SDK built over PostgreSQL 19 and
C ABI v1.3.

## Included

- open-or-create and explicit cluster-open modes;
- multiple live instances with one owner process per cluster;
- concurrent logical connections through a bounded executor;
- materialized and chunked results;
- simple and extended protocol execution;
- prepared statements;
- COPY IN and COPY OUT;
- structured errors, notices, notifications, logs, and overflow events;
- checkpoint and maintenance operations;
- in-process logical dump and restore;
- optional Arrow C Data export;
- DB-API 2.0 and caller-driven asyncio adapters;
- bundled pgvector 0.8.6 with HNSW, IVFFlat, parallel-build, concurrency, and
  close/reopen validation;
- a reviewed native-extension SDK;
- a symbol-isolated static C SDK and matching resource pack; and
- CPython wheels with the kernel statically incorporated.

## Supported release boundary

- Linux x86-64;
- glibc 2.28 or newer for official manylinux wheels;
- CPython 3.10 through 3.14;
- PostgreSQL cluster major 19;
- one read-write operating-system process owner per cluster directory.

Read [limits and unsupported features](../compatibility/limits.md) before
deploying this alpha.

## Data compatibility

Direct cluster compatibility with a later alpha is not promised by this
candidate. Make a logical dump before upgrading and retain the source cluster
until restore verification succeeds. See the [release index](index.md) for the
general alpha upgrade rule.

## Publication status

Source and artifact gates can build, install, execute, and inspect the release
matrix. PostGamma-owned source is licensed under Apache-2.0. Public
distribution still requires the complete manylinux execution evidence and
explicit release-owner authorization.
